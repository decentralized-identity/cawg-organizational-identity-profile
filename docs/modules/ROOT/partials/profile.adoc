== Profile definition

An implementation of the *Organizational Identity Profile for Content Credentials* MUST:

* Support the https://spec.c2pa.org/specifications/specifications/2.3/specs/C2PA_Specification.html[C2PA Content Credentials Specification], version 2.2 or 2.3.
* Support the `cawg.x509.cose` signature type in the https://cawg.io/identity/1.2/[CAWG Identity Assertion], version 1.2.
* Support the https://cawg.io/metadata/1.1/[CAWG Metadata Assertion], version 1.1.

[NOTE]
====
CAWG will review updates to each of these specifications and issue a new version of this profile as appropriate to add support for those versions.
====
